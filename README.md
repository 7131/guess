# SiteswapGuessr game

English site: https://7131.github.io/guess/<br>
Japanese site: https://app.7131.jp/guess/

This is a game where you guess what the siteswap being performed by the character on the screen is.
While there are already games where the only outcome is whether the answer is correct or incorrect, this game introduces a partial-point system and allows players to receive hints in stages, thereby enriching the gaming experience.

In addition to vanilla siteswaps, multiplex and synchronous patterns also appear.
All of these are generated randomly on the spot based on the specified values.
